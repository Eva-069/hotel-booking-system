# Діаграми пояснювальної записки

`build_diagrams.py` — єдине джерело всіх діаграм (рис. 1.1 контекстна діаграма; 2.1–2.3 DFD; 2.4 варіанти
використання; 2.5 послідовність; 2.6 стани; 2.7 архітектура; 2.8 ERD). Запуск: `python3 build_diagrams.py`
(потрібен matplotlib), результат — `png/`. Зображення, вставлені в записку, відтворюються цим кодом
піксель у піксель (перевірено порівнянням).
